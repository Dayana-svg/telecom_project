# TelecomChurnBot
Telegram-бот для прогнозирования оттока клиентов.

## Установка
\`\`\`bash
pip install -r requirements.txt
\`\`\`
## Использование
\`\`\`bash
python bot.py
\`\`\`

## Команды Telegram
- `/start` - начало работы
- `/predict <ID>` - прогноз оттока
Пример:
\`\`\`bash
/predict 123
\`\`\`
